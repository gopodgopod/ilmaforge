# GHX — 3D Scenes

User-owned material supplied for a separate project:
https://drive.google.com/drive/folders/1qtGREbsP5kR-YGapfYjW5ZEI6KpYDwRk

Copied from matching local originals in `GHX Trailer/Behance/strona_ghx/strona grafika` and `GHX Trailer/Behance/GIF`. JPEG files retain their source filenames. Hero_ghx_main.jpg is the homepage thumbnail, without the layout wordmark.

The nine animated GIFs were converted to silent looping H.264 MP4 (CRF 16, original dimensions, frame timing retained, faststart) for browser playback and the 25 MiB Pages file limit. Only pawilon.gif received one bottom padding pixel for H.264 even dimensions. Source names, dimensions and durations are recorded in media.json. Posters are animation frames. Both viewport and final sequences remain animated; no player chrome is displayed.

Copy was transcribed from the supplied layout as HTML text. Main film is pending; the still is a placeholder, not a player.
