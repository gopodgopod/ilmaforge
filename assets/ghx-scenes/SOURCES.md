# GHX — 3D Scenes

Images and animations supplied by the site owner for this separate project. JPEG files retain their original filenames. Hero_ghx_main.jpg is the homepage thumbnail without the layout wordmark.

The nine animated GIFs were converted to silent looping H.264 MP4 (CRF 16, original dimensions, frame timing retained, faststart) for browser playback and the 25 MiB Pages file limit. Only pawilon.gif received one bottom padding pixel for H.264 even dimensions. Source filenames, dimensions and durations are recorded in media.json. Posters are animation frames. Viewport and final sequences remain animated; no player chrome is displayed. The two globe animations are render variations rather than viewport/final pairs.

Copy is HTML text transcribed from the supplied layout. The main film is pending; its still is a labelled placeholder.
